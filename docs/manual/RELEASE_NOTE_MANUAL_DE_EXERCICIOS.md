# Release Note — Manual de Execução

## Novo: Manual de Execução dos exercícios

O Kegel_Coach agora inclui um guia integrado para ajudar o usuário a aprender a técnica correta dos exercícios do assoalho pélvico.

### Incluído
- orientação passo a passo;
- contrações lentas guiadas;
- contrações rápidas;
- animações discretas;
- dicas para manter a respiração;
- erros comuns;
- orientação de relaxamento;
- recomendações de segurança;
- referências especializadas.

O manual funciona offline e pode ser consultado sempre que necessário.

As animações foram planejadas para reforçar que a contração é predominantemente interna, evitando representar movimentos externos exagerados que poderiam induzir à técnica incorreta.

### Nota
O conteúdo é educativo e não substitui avaliação médica ou fisioterapêutica individual.

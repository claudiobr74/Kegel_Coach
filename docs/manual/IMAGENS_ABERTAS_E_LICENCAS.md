# Imagens anatômicas abertas e licenças

Estas imagens foram selecionadas como fontes anatômicas reais/confiáveis para eventual uso no app ou para orientar o design.

> IMPORTANTE: os arquivos externos não são necessários para o funcionamento do manual animado incluído neste ZIP. Ao incorporá-los ao app, baixar sempre o original a partir da página oficial e preservar os termos de licença.

## Regra para o Work

Antes de incorporar qualquer imagem de terceiros:
1. confirmar novamente a página oficial;
2. confirmar a licença;
3. registrar autor, origem e licença;
4. adicionar atribuição quando exigida;
5. evitar assets com licença incompatível com a distribuição planejada;
6. se houver dúvida jurídica/licenciatória, não incluir o asset no APK até revisão.

## Preferência de produto

Para o guia de execução, as animações abstratas incluídas no ZIP são preferíveis, pois evitam ensinar movimentos anatômicos externos irreais.

As imagens anatômicas devem servir para a seção educacional “Onde fica o assoalho pélvico”, não como substituto da animação do ritmo do exercício.
